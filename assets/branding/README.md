# mcpd branding

The primary MCPD mark is **Signal Core**: a compact set of concentric signal paths and orbit nodes representing a central MCP hub coordinating tools, clients, and resources. The mark deliberately avoids letterforms so it can stand alone as a recognizable product symbol.

## Asset

- `mcpd-signal-core.webp` — lossless transparent WebP master for product UI, documentation, favicon/app-icon derivations, and authorization surfaces.

The OAuth package embeds the same WebP at build time from `internal/oauth/assets/mcpd-signal-core.webp` so installed single-binary deployments do not depend on external static files.

## Core colors

- Signal violet: `#6F37E8`
- Signal lavender: `#996FF6`
- Deep violet: `#4527A0`
- Ink: `#111427`
- Surface: `#FFFFFF`

Keep the mark proportional, preserve clear space around the outer signal ring, and do not replace it with initials or a letter-based fallback.
